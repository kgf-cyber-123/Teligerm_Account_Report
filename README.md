## 📌 About The Project

**Telegram Account Report Tool** is a powerful and automated command-line utility designed to handle and report fake, scam, or impersonation accounts on Telegram efficiently. Built with performance and accuracy in mind, this tool allows users to secure the Telegram community by identifying and flagging malicious profiles seamlessly using Termux or Linux environments.

> ⚠️ **Disclaimer:** *This tool is created strictly for educational purposes and cybersecurity awareness. The developer is not responsible for any misuse or damage caused by this software.*

---

## ✨ Key Features

* 🔥 **Automated Reporting:** Fast and multi-threaded report execution for target accounts.
* 🛡️ **Advanced Security Bypass:** Designed to work smoothly under standard API constraints.
* 📱 **Termux Optimized:** Fully compatible with Android devices via Termux and Linux distributions.
* ⚡ **Lightweight & Fast:** Written in pure Python for high efficiency and minimal resource usage.
* 🎨 **User-Friendly Interface:** Clean terminal UI with step-by-step interactive prompts.
